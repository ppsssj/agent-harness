Complete the sections in order--Reference Evidence, Element Map, Major Visual Decision Map, Design Synthesis Proposal, Human Approval--before application source or style implementation. Do not backfill this record after implementation as evidence of prior reasoning.

## Element Map

| Site A | Hero composition | PRESERVE |  |
| Site B | Card layout | PRESERVE |  |
| Site B | Card color | ADAPT | Use existing cobalt brand |
| Product | Trace motif | INVENT | Derived from workflow |

**PRESERVE:** use a strong inspected reference decision when no concrete project reason requires changing it.

**ADAPT:** change a reference element only for a concrete reason, such as existing brand or design-system constraints, product semantics, accessibility, responsive behavior, performance, or reconciliation with another reference.

**INVENT:** add an element when references do not solve a product-specific need or when it reconciles selected references. INVENT is not required in every design.

## Major Visual Decision Map

Complete this map before the Design Synthesis Proposal. Include only the major decisions that define the resulting page; do not require irrelevant categories.

| Major decision | Proposed treatment | Provenance | Decision |
| --- | --- | --- | --- |
| Background / tonal treatment | White editorial field | REFERENCE: Site A | PRESERVE |
| Accent color role | Cobalt signal | EXISTING BRAND / DESIGN SYSTEM + REFERENCE: Site B role | ADAPT |
| Hero typography | Oversized condensed sans | REFERENCE: Site C | PRESERVE |
| Project presentation | Asymmetric index | REFERENCE: Site D | PRESERVE |

Use only these provenance sources: **REFERENCE**, **EXISTING BRAND / DESIGN SYSTEM**, **PRODUCT REQUIREMENT**, or **ACCESSIBILITY / TECHNICAL CONSTRAINT**. The evidence must support the proposed treatment at this level of specificity. "Looks good," "fits the vibe," model familiarity, or retrospective association are not provenance.

This is decision-level provenance, not a requirement to copy exact implementation values. A reference-supported warm off-white background may use a calibrated hex; a supported display-typography treatment may use a suitable font, size, line-height, and tracking.

For an INVENT row, record the unmet product-specific need, why inspected references do not solve it, and the proposed invention before implementation and approval. Do not use INVENT retrospectively to justify an implemented aesthetic choice.
