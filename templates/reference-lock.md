**PRESERVE:** use a strong inspected reference decision when no concrete project reason requires changing it.

**ADAPT:** change a reference element only for a concrete reason, such as existing brand or design-system constraints, product semantics, accessibility, responsive behavior, performance, or reconciliation with another reference.

**INVENT:** add an element when references do not solve a product-specific need or when it reconciles selected references. INVENT is not required in every design.

## Final Synthesis
